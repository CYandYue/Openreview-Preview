### Q1. Motivation
**Key point.** Our method supports $\\alpha$.

$$
\\frac{a}{b} = 0.8
$$

Use $...$ for inline math and $$...$$ for display math. In a Markdown-enabled field, escape each formula backslash. Matrix or aligned line breaks need four backslashes \\\\ in the source, leaving the two required by LaTeX after Markdown parsing.

Escape underscores when they conflict with Markdown emphasis, for example $x\_i$. Use Markdown for headings, emphasis, lists, and tables. Image embeds and inline HTML follow OpenReview's restrictions.

Files, drafts & character counts

Edit on the left or open a .md file. Browsers with the File System Access API can follow saves from VS Code or another editor. Typing here automatically pauses file following.

Drafts are saved in this browser. They are not written back to the original file. Use “Download .md” to save a copy and “Copy Markdown” to paste into OpenReview. ⌘/Ctrl + S downloads your draft.

The default limit is 5000 characters; adjust it to match your venue's field. The counter uses text.trim().length, including Markdown and formulas. Download your draft for a durable backup.

Marked, DOMPurify, MathJax, and math fonts run locally. The rendering rules are based on OpenReview's source. Font, width, field configuration, and site versions can differ; check the official Preview before submitting.
